# Сборка MojaveRay вручную в Xcode

1. Отключите VPN, закройте старый MojaveRay и распакуйте архив в новую папку на Intel‑Mac.
2. Откройте файл `MojaveRay.xcodeproj` двойным щелчком.
3. В верхней панели Xcode выберите схему **MojaveRay** и устройство **My Mac**.
4. Выполните **Product → Clean Build Folder** либо нажмите **⇧⌘K**.
5. Нажмите кнопку **▶︎ Run** или сочетание **⌘R**.
6. При первой сборке Xcode загрузит совместимые версии Xray и tun2socks. Это
   может занять несколько минут.
7. После запуска вставьте VLESS‑ссылку, нажмите «Сохранить ключ», выберите
   «Полный VPN — весь трафик» и нажмите «Подключить».
   Если профиль уже сохранён, повторно вставлять ссылку не нужно.
8. Один раз подтвердите установку системного помощника паролем администратора.
9. Отключите и повторно подключите VPN: административного запроса больше быть не должно.

Пароль снова потребуется при переустановке/удалении службы или её обновлении.
В меню **MojaveRay** добавлены команды переустановки и удаления помощника.
Проверить установленную версию приложения можно в **MojaveRay → О MojaveRay**:
должна быть версия **1.6**.

## Если GitHub не открывается

Скачайте на другом устройстве файлы:

- `Xray-macos-64.zip` версии 1.8.1;
- `Xray-macos-64.zip.dgst` версии 1.8.1;
- `tun2socks-darwin-amd64.zip` версии 2.5.0.

Не распаковывая и не переименовывая, положите их в папку `Загрузки` текущего
пользователя и снова нажмите **⌘R** в Xcode.

## Где найти готовое приложение

После успешного запуска выберите в меню Xcode:

`Product → Show Build Folder in Finder`

Затем откройте `Products/Debug` или `Products/Release`. Там находится
`MojaveRay.app`, который можно перенести в папку «Программы».

Проект рассчитан на macOS 10.14.6 и архитектуру Intel x86_64. Учётная запись
Apple Developer для локальной сборки не требуется.
